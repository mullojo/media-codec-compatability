How to read this report
Yes means the API reports support for the tested configuration; No means it reports no support. Unknown means the API is unavailable, a query failed, or it timed out. Codec profiles, bit depth, drivers, OS, browser settings and power mode can change the result.
These are capability predictions, not actual playback or encoding tests. They do not measure speed, verify hardware acceleration, or guarantee every file will work. Media Source support does not test a streaming service or DRM.
